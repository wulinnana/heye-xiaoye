# 合成宵夜

搪瓷夜档风、地图闯关。六个城市各有一条招牌食物链，合成过关。不需要自建服务器。

**城市：** 香港大排档 → 广州夜市 → 长沙解放西 → 成都撸串 → 西安回民街 → 重庆江边。通关一城解锁下一城，也可看广告提前开张。

## 本地预览

用浏览器打开 `index.html`，或在项目目录执行：

```bash
npx --yes serve -p 5173
```

然后访问 `http://localhost:5173`。未配置广告 ID 时会走「广告预览」：倒计时结束后照样发奖，方便你点完所有变现入口。

## 导入微信开发者工具

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择 **小游戏** → 导入本目录
3. AppID 可先用测试号，正式上线改成你的小游戏 AppID（`project.config.json` 里的 `appid`）
4. 编译后即可在模拟器里玩

## 广告位（变现）

登录 [微信公众平台](https://mp.weixin.qq.com) → 流量主 → 广告管理，创建以下 3 个广告位，把 ID 填进 `js/config.js` 的 `ads`：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `rewarded` | 激励视频 | 复活、幸运掉落、消除危机、金币翻倍、领金币、开局好运 |
| `interstitial` | 插屏 | 结算后「再来一局 / 回首页」 |
| `banner` | Banner | 首页、图鉴、结算页底部 |

ID 需形如 `adunit-xxxxxxxx`。三个都填好后，预览模式会自动关掉，改为拉取真实广告。

激励视频都是玩家主动点的，符合流量主「用户主动触发」要求。

## 分享（推广）

- 右上角菜单分享 / 朋友圈：带当前分数
- 首页「分享有礼」：每天第一次分享送 1 次幸运掉落
- 局内「分享得道具」、结算「分享战绩」：把最高合成物写进文案，方便裂变

## 上架清单

- 小游戏账号已认证，开通流量主
- 替换 AppID，上传代码
- 准备 1080×1080 图标、分享封面（可用游戏截图）
- 填写隐私协议（本游戏只用本地存储，无用户登录、无服务端）
- 本游戏无内购，走广告变现，一般不需要版号；若之后加内购必须先申请版号
- 提交审核时说明：单机合成、本地存档、激励视频道具

## 核心文件

- `js/config.js` — 食材表、价格、广告 ID
- `js/ads.js` — 激励 / 插屏 / Banner
- `js/scenes/play.js` — 合成玩法与局内道具
- `game.js` — 微信小游戏入口
